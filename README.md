# Medical-History-Analysis
Overview

Medical Data History Analysis is a healthcare analytics project focused on extracting meaningful insights from patient, admission, doctor, and geographical data using SQL and Power BI. The project demonstrates the application of database querying, data analysis, and dashboard development to solve real-world healthcare business problems.

Tools Used
SQL (MySQL)
Power BI
Excel

Project Objectives
Analyze patient demographics and healthcare records.
Examine hospital admission trends and diagnosis patterns.
Explore doctor-patient relationships and workload distribution.
Generate actionable insights through data visualization and reporting.

Key Features
Solved 34 business-oriented SQL queries.
Applied joins, aggregations, grouping, filtering, date functions, and CASE statements.
Performed healthcare analytics including obesity classification, allergy analysis, and diagnosis trends.
Developed an interactive Power BI dashboard with key healthcare KPIs and visual insights.

Dashboard Insights
Total Patients and Admissions
Gender Distribution Analysis
Common Medical Conditions
Allergy Trends
Obesity Rate Analysis
Doctor Workload Distribution
Geographic Patient Distribution

Key Outcomes

The project demonstrates proficiency in SQL-based data analysis, relational database concepts, healthcare analytics, and dashboard development. It highlights the ability to transform raw healthcare data into meaningful insights that support data-driven decision-making.
